# OvaScreenUI

Desktop-приложение для визуализации результатов AI-сегментации опухолей яичников на основе DICOM-снимков.

## О проекте

OvaScreenUI - клиентская часть программного комплекса для медицинской диагностики. Приложение взаимодействует с сервером на базе FastAPI, который с помощью нейросети U-Net обрабатывает DICOM-снимки и выделяет область опухоли. Интерфейс позволяет загружать снимки, просматривать результат наложения маски и регулировать её прозрачность.

**Важно:** Приложение работает только совместно с запущенным сервером, выполняющим AI-обработку изображений.

## Возможности

- Загрузка DICOM-файлов через диалоговое окно
- Отправка файла на сервер для анализа
- Отображение исходного УЗИ с наложенной маской сегментации
- Вертикальный ползунок для регулировки прозрачности маски (0-100%)
- Логирование всех действий и результатов в текстовом поле
- Индикатор доступности сервера при запуске

## Технологии

- **Язык:** C#
- **Фреймворк:** .NET 6.0 (WinForms)
- **HTTP-клиент:** HttpClient
- **Обработка JSON:** Newtonsoft.Json
- **Работа с изображениями:** System.Drawing
